# Расписание — iPhone-приложение (SwiftUI)

Приложение само скачивает Excel-файлы расписания с публичной папки Яндекс.Диска,
разбирает их на телефоне (та же логика, что в Telegram-боте) и показывает красивое
расписание. Можно подписаться на группы — они сохраняются на устройстве.

## Как собрать IPA

1. Создайте пустой репозиторий на GitHub и загрузите в него **всё содержимое этой папки**
   (важно: папка `.github` с workflow должна попасть в репозиторий).
2. Откройте вкладку **Actions → Build IPA → Run workflow** (или просто сделайте push в `main`).
3. Когда сборка закончится (≈5–8 минут), скачайте артефакт **Schedule-ipa** → внутри `Schedule.ipa`.
4. IPA собирается **без подписи** — подпишите своим сертификатом так же, как вы делаете это
   с остальными приложениями, и установите.

Bundle ID по умолчанию: `com.rasp.schedule` (меняется в `project.yml`).
Минимальная iOS: 18.0.

## Что внутри

- `Parsing/` — чтение `.xls` (OLE2/BIFF8) и `.xlsx` (ZIP+XML) без сторонних библиотек,
  порт разбора из бота: объединённые ячейки, опечатки в днях недели, электив на выбор,
  «СЕССИЯ»/«ГИА», удаление дублей.
- `Network/YandexDisk.swift` — обход папки (с вложенными), скачивание с проверкой md5 и кэшем.
- `Store/ScheduleStore.swift` — данные, подписки (UserDefaults), кэш на диске.
- `UI/` — экраны: расписание, группы, настройки.
- `Resources/meals.json` — график питания из бота.

Ссылку на папку Яндекс.Диска можно поменять в приложении: **Ещё → Источник расписания**.

## Возможности

- Расписание групп, преподавателей и кабинетов (поиск, избранное, свободные кабинеты по корпусам).
- Учебный график: PDF с сайта колледжа разбирается на устройстве (по координатам символов,
  логика как в боте) в карточки периодов: сессии, практики, каникулы, ГИА, с датами,
  обратным отсчётом и полоской всего года. Оригинал PDF открывается из меню «…».
- Экран загрузки с прогрессом: пока данные не обновились, расписание закрыто;
  если сети нет — можно открыть сохранённое.
- Космическая тема и стекло Liquid Glass. Сборка идёт на `macos-26` (Xcode 26),
  поэтому на iOS 26/27 включается настоящее системное стекло и нативная панель вкладок.
  Если сборка на `macos-26` не пойдёт — верните `runs-on: macos-15`, приложение
  соберётся со своим стеклом.

Минимальная iOS: 18.0.
